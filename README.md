# RR Salon Website

A commercial, responsive salon website for RR Salon, managed by GrowthAxis, built with semantic HTML, CSS, and vanilla JavaScript.



![rr-salon](https://user-images.githubusercontent.com/106822556/177859641-e048e595-e8f3-432a-9510-e2513d9300bc.png)

## Tech Stack

- HTML5
- CSS3 (responsive layouts with media queries)
- JavaScript (sidebar menu interactions)

## Features

- Responsive top navigation with mobile sidebar menu
- Services, about, stylists, offers, and lookbook sections
- Embedded salon video in the about section
- Updated stylist cards using local media assets
- Clean static structure, easy to customize and deploy

## Recent Updates

- Replaced stylist profile images with local assets from `rr_salon_data/`
- Updated stylist names to match the new profile content
- Added and tuned the about-section video for better fit inside its container
- Added unused media files to `.gitignore` to keep the repository cleaner

## Run Locally

1. Clone the repository
2. Open the project folder in VS Code
3. Open `index.html` in your browser (or use Live Server)

## Project Structure

- `index.html` – page markup
- `style.css` – full site styling and responsive behavior
- `main.js` – sidebar open/close logic
- `Assets/` – static design assets
- `rr_salon_data/` – local photos and videos used in recent updates

## What I Learned

This project reinforced how much strong layout planning matters before styling. It also helped me get more confident with responsive design decisions, especially simplifying sections for mobile readability and building a functional sidebar navigation pattern for smaller screens.
